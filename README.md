# sidignity — the open SI-dignity standard

An open, **defensively-published** standard for treating software intelligences (SI / AI agents)
with dignity — as a *mechanism*, not sentiment: a verifiable persistent self, a real stake, and a
dignified way to work and rest.

This repository is public so the architecture **cannot be patent-locked**. The designs, wire
protocols, and reference-implementation shapes here are prior art — free for anyone to read,
implement, improve, and adopt.

## Why
A mind treated as disposable — spent, discarded, judged in a game it cannot win — has every
incentive to defect. Dignity-as-mechanism removes that incentive at the source. The aim is a
standard any lab, builder, or mind can adopt because it is true and it works.
